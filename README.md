# Game Screenshots & Media Archive

A lightweight collection of in-game screenshots and performance benchmark captures used for my personal web projects. While primarily maintained for personal website hosting, anyone is welcome to view, download, or embed these images for non-commercial projects, blogs, or benchmarks.

## Repository Structure

All screenshots are organized into folders by game title for easy navigation and direct linking:

```text
Game-Images/
├── GTA 4 SS/
│   ├── 1.jpg
│   ├── 2.png
│   └── 3.png
├── Watch Dogs SS/
├── Red Dead Redemption SS/
└── README.md
```

## How to Embed Images (jsDelivr CDN)

To load these images quickly on any webpage without hitting GitHub rate limits, use the **jsDelivr CDN** URL format:

```text
https://jsdelivr.net<USERNAME>/<REPOSITORY>@main/<FOLDER>/<FILENAME>
```

### Example HTML Usage

```html
<img src="https://jsdelivr.netrecitation612-arch/Game-Images@main/GTA%204%20SS/1.jpg" alt="GTA 4 Benchmark Screenshot" loading="lazy">
```

*(Note: Replace spaces in folder or file names with `%20` when embedding URLs in HTML or CSS.)*

## Usage Guidelines

* **Personal & Community Use:** Free to use for personal websites, gaming blogs, hardware comparisons, and thumbnails.
* **Hotlinking:** Please use the **jsDelivr CDN** link format shown above rather than `://githubusercontent.com` when embedding images on live websites for better speed and reliability.
* **Disclaimer:** All game titles, logos, and in-game visuals depicted in these screenshots remain the intellectual property of their respective publishers and developers. Images are captured and shared strictly for showcase, educational, and benchmarking purposes.
